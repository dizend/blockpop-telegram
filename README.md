# БлокПоп! — Telegram Mini App 🎮

Игра «БлокПоп!» (слияние блоков в стиле 2048 с бросками) как мини-приложение Telegram.
Один самодостаточный файл `index.html` — Canvas + WebAudio, без внешних зависимостей.

## Что внутри

- `index.html` — вся игра одним файлом, готова для Telegram Mini Apps:
  - Telegram WebApp SDK (`telegram-web-app.js`), `expand()`, отключение вертикальных свайпов
  - Вибрация через Telegram HapticFeedback (fallback — `navigator.vibrate`)
  - Рекорды в Telegram CloudStorage (синхронизируются между устройствами; fallback — localStorage)
  - Кнопка «Поделиться» результатом через Telegram
  - Приветствие по имени пользователя Telegram
  - Вне Telegram (в обычном браузере) игра тоже полностью работает

## Шаг 1. Разместить игру (GitHub Pages)

Telegram Mini App — это просто веб-страница по HTTPS-ссылке.

1. Залейте `index.html` в репозиторий GitHub (в корень, ветка `main`).
2. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. Через 1–2 минуты игра будет доступна по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
4. Откройте ссылку в браузере и убедитесь, что игра запускается.

> ⚠️ На бесплатном плане GitHub Pages работает только в **публичных** репозиториях.
> Альтернативы с приватным репо: GitHub Pro, Cloudflare Pages, Netlify, Vercel.

## Шаг 2. Создать бота и подключить Mini App

1. В Telegram откройте **@BotFather** → команда `/newbot`.
2. Придумайте имя (например, `БлокПоп!`) и username бота (например, `BlockPopGameBot`).
3. Команда `/newapp` → выберите своего бота:
   - Title: `БлокПоп!`
   - Description: `Бросай блоки, сливай одинаковые и собери 2048!`
   - Photo: картинка 640×360 (любой скриншот игры)
   - Web App URL: ссылка из Шага 1
   - Short name: например `play` — получится прямая ссылка `https://t.me/BlockPopGameBot/play`
4. Дополнительно (рекомендуется): `/mybots` → ваш бот → **Bot Settings → Menu Button** → задайте ту же ссылку, чтобы игра открывалась кнопкой прямо в чате с ботом.

## Шаг 3. Включить кнопку «Поделиться»

В `index.html` в самом начале скрипта найдите строку:

```js
var TG_BOT_URL = '';
```

и впишите прямую ссылку на вашу мини-игру:

```js
var TG_BOT_URL = 'https://t.me/BlockPopGameBot/play';
```

Тогда кнопка «Поделиться» будет отправлять друзьям ссылку на игру вместе с результатом.

## Проверка

- Откройте `https://t.me/<ваш_бот>/<short_name>` на телефоне — игра должна открыться во весь экран.
- Рекорд сохраняется в облаке Telegram — проверьте, что после перезапуска он на месте.
- Вибрация работает только на телефоне (в десктопном Telegram её нет — это нормально).

## Локальный запуск для разработки

Просто откройте `index.html` в браузере. Управление на компьютере:
стрелки ←/→ — выбор колонки, ↓ или пробел — бросок, P/Esc — пауза.
